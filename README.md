# My English

Особистий словник-зошит. Працює офлайн, дані зберігаються на пристрої (localStorage).

## Як відкрити на айфоні
1. Розпакуйте архів. Зайдіть на https://app.netlify.com/drop і перетягніть туди всю папку `my-english`.
2. Відкрийте отримане посилання в Safari.
3. «Поділитися» → «На екран "Додому"».

## Резервна копія
Іконка ⚙︎ на головному екрані: експорт і імпорт JSON.

## Оновлення
Змінивши файли, завантажте їх на Netlify знову (Deploys → drag and drop). Дані на телефоні збережуться.
